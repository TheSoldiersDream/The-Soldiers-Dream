# The Soldiers Dream

An autonomous agents application framework for coordinated multi-agent systems.

## Projects

### Amigos Agent App

Located in `/amigos-agent-app/` - A Python-based autonomous agents framework that simulates military-style coordination between different types of AI agents.

**Features:**
- Multi-agent coordination system
- Scout, Combat, Support, and Command agent types
- Asynchronous task execution
- Configurable agent capabilities

**Usage:**
```bash
cd amigos-agent-app
python main.py
```

See the [Amigos Agent App README](./amigos-agent-app/README.md) for detailed information.
