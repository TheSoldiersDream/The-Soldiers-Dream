# The Soldiers Dream - Agent Amigos App

This repository contains the **Agent Amigos App**, a sophisticated autonomous agent management platform built with modern web technologies.

## 🚀 Quick Start

```bash
# Install all dependencies
npm run install:all

# Start development servers (backend + frontend)
npm run dev
```

Access the application at http://localhost:3000

## 📁 Project Structure

```
├── .vscode/                 # VS Code configuration
├── amigos-agent-app/        # Main application directory
│   ├── backend/             # Node.js + Express API server
│   ├── frontend/            # React + TypeScript client
│   └── shared/              # Shared types and utilities
├── package.json             # Root package configuration
└── README.md               # This file
```

## ✨ Features

- **🤖 Agent Management**: Create and manage autonomous agents with different capabilities
- **📋 Task Assignment**: Assign and monitor tasks in real-time
- **⚡ Real-time Updates**: WebSocket integration for live status updates
- **🎨 Modern UI**: Clean, responsive interface with Tailwind CSS
- **🔧 VS Code Integration**: Complete development environment setup

## 🛠 Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js, WebSocket
- **Development**: VS Code, ESLint, Prettier, Hot Reload
